# Algorithms in JS 🟨

## Setup

```bash
git clone https://github.com/jeanpaulsio/algorithms-in-js.git
asdf install
yarn install
```

## Running Tests

```bash
# Run all tests
yarn test

# Run tests in watch mode
yarn test:watch
```
